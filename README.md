# 🦜🕸️ LangGraph Practice & Experiments

Welcome! This repository serves as my hands-on playground and learning log for building LLM agents using **LangGraph** and modern AI frameworks. 

As a beginner in the agentic AI space, I am using this repository to practice core concepts, follow tutorial implementations, and build intuition around graph-based state management for multi-step AI workflows.

---

## 📌 Objectives & Scope

- **Understand LangGraph Core Concepts:** Working with state management, nodes, edges, conditional edges, and human-in-the-loop interactions.
- **Agent Architecture:** Moving from simple linear chains to dynamic, cyclic agent patterns (e.g., ReAct agents, supervisor patterns, memory systems).
- **Tool Calling:** Integrating search APIs, calculators, custom Python execution tools, and external services into autonomous agent workflows.
- **Hands-on Tutorials:** Experimenting with reference code from official LangChain/LangGraph docs and community tutorials.

---

## 🛠️ Tech Stack & Tools

- **Framework:** LangGraph / LangChain
- **Language:** Python 3.10+
